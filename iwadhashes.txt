# ZandroX downloadable IWAD hashes -- the gate.
#
# A downloaded file that will be loaded as a game is kept only if its SHA-256 is listed here. Not its
# name: its bytes. Why it works this way is in features/wad-download/README.md.
#
#   <sha256>    <filename>    <what it is>
#
# Case-insensitive. Blank lines and # ignored. The filename must also be in iwadallowlist.txt, or the
# build fails. Missing a build is safe -- the download is refused, never accepted.
#
# To add one: get the file from the project's own release page, not a WAD mirror (hashing a mirror's
# copy and calling it canonical is circular). Verify a published signature or checksum if there is
# one, note the provenance in your PR, then sha256sum the extracted IWAD.
