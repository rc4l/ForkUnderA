# ZandroX server registries
# format-version: 1
#
# The list of server registries a ZandroX client queries to find servers. This file is the source of
# truth; clients do not read it from here directly.
#
# Unlike its neighbours in config/, this one is NOT compiled into the binary -- it is published. It is
# served through a CDN that caches this copy, and each client refreshes from the CDN at most every 6
# hours -- so a server registry can be added here and reach players without shipping a release, and
# GitHub never sees per-player traffic.
#
# If this file MOVES, repoint rc4l/server-registry-rc4l serverregistrylist-cdn/worker.js (SOURCE) --
# it pins a raw.githubusercontent path on main. Forgetting breaks fresh installs, silently.
#
# A fetch that fails, times out, or comes back as anything other than a list (an error page, a bot
# challenge) is treated as a failure: the client keeps its cached copy, and failing that, the copy
# compiled into the engine. A bad fetch can never leave a player with no server registries.
#
# Querying a server registry carries no authority: it hands back server ADDRESSES and nothing else,
# and the client then asks each server directly for its name, map and players. Being listed here
# therefore does not let a server registry moderate anyone -- that only happens between a server and
# the ONE server registry it announces to (fua_serverregistry_host).
#
# Deliberately line-based rather than JSON: this file is edited by pull request, and a line-based
# format diffs cleanly and cannot be broken for everyone by one missing comma.
#
# One server registry per line:
#   <host>[:port]    <display name>
#
# Blank lines and lines starting with # are ignored. Port defaults to 15300 when omitted.
# Unparseable lines are skipped rather than failing the file -- a bad entry costs its own listing and
# nothing else.
#
# To add yours: open a PR adding one line. To run one, see
# https://github.com/rc4l/server-registry-rc4l
#
# Players can add server registries locally without touching this file:
#   cl_fua_serverregistry_list "registry.example.net, another.example.org"
