// [rc4l] Sounds for the quake-movement master E2E. See MASTERTEST.md section "Sound".
//
// Every sound this feature plays is a PLAYER sound (a "*name"), and stock Doom defines none of
// them -- *jump, *edgejump, *secondjump, *footstep, *crouchslide and *wallclimb are all new. So
// without this lump the entire sound surface is silent, and "I heard nothing" would be
// indistinguishable from "the code never called S_Sound". Mapping them to deliberately unalike
// stock lumps is what makes a listening test able to tell the six events apart.
//
// Chosen for contrast, not realism:
//   switch click / powerup chime / item blip   -- three sharply different one-shots
//   stone rumble / chainsaw idle               -- two continuous sounds that loop cleanly
//
// The two loops matter most: they are started with CHAN_BODY|CHAN_LOOP and only ever stopped on
// the transition edge, so a stuck loop is audible immediately.
//
// Each gender is spelled out rather than using $playersounddup: that directive's last argument is
// another LOGICAL SOUND NAME within the same class/gender, not a gender to copy from, so
// "$playersounddup player female *jump male" is a parse error ("male is not a player sound").

$playersound		player	male	*jump			DSSWTCHN
$playersound		player	male	*secondjump		DSGETPOW
$playersound		player	male	*edgejump		DSITEMUP
$playersound		player	male	*footstep		DSPSTOP
$playersound		player	male	*crouchslide	DSSTNMOV
$playersound		player	male	*wallclimb		DSSAWIDL

$playersound		player	female	*jump			DSSWTCHN
$playersound		player	female	*secondjump		DSGETPOW
$playersound		player	female	*edgejump		DSITEMUP
$playersound		player	female	*footstep		DSPSTOP
$playersound		player	female	*crouchslide	DSSTNMOV
$playersound		player	female	*wallclimb		DSSAWIDL

$playersound		player	other	*jump			DSSWTCHN
$playersound		player	other	*secondjump		DSGETPOW
$playersound		player	other	*edgejump		DSITEMUP
$playersound		player	other	*footstep		DSPSTOP
$playersound		player	other	*crouchslide	DSSTNMOV
$playersound		player	other	*wallclimb		DSSAWIDL
